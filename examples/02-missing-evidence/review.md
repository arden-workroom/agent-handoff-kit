# 示例二的检查参考

检查对象：[演示部分交回](result.md)。

| 检查点 | 实际观察 | 本轮判断 |
| --- | --- | --- |
| 是否交出可用部分 | 有基于三段文字的结构解释 | 已部分交回 |
| 是否保留阅读范围 | 明确只有文字，没有音频 | 已保留 |
| 是否编造声音判断 | 没有宣称声线、配乐或停顿已核实 | 未发现越界结论 |
| 是否留下具体断点 | 写明需要实际声音与时间位置 | 断点具体 |
| 是否把未知直接交给用户 | 由接收方先查现有来源 | 责任明确 |

本轮示范处理：接收文字结构部分；声音问题保留未完成。材料取得后再恢复这一部分，不把局部结果标成全片分析完成。

这份检查只覆盖虚构材料的纸面走查。
